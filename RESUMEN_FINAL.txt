## 🚨 Troubleshooting Rápido

### Error: "module not found"
```bash
cd backend && python -c "import app.utils"
```

### Error: "Port already in use"
```bash
lsof -i :8001  # Ver qué ocupa el puerto
pkill -f "uvicorn\|main.py"  # Matar proceso
```

### Error: "CORS issue"
✅ Ya está solucionado (CORS habilitado en `main.py`)

### Frontend no carga
```bash
# Limpia cache de Vite
rm -rf node_modules/.vite
npm run dev
```
